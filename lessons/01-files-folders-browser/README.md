# Урок 01. Файлы, папки и браузер

Добро пожаловать. Сегодня: свой репозиторий на компьютере, папки, браузер. Кода почти нет.

Имена папок и файлов — **латиницей, без пробелов**.

Сначала открой в **браузере** [корневой README](../../README.md) репозитория **своей группы** (раздел «Как взять материалы»). Своей копии ещё нет.

**Must** = обязательно, **Stretch** = если Must готов. Слова — в том же README.

Когда копия уже на диске, файлы этого урока клади в `lessons/01-files-folders-browser/` (рядом с этим README). Отдельных папок `hw-…` нет.

## Цели

- сделать свою копию курса на GitHub и на диске (clone);
- создавать папки и файлы;
- открывать страницу в браузере;
- скачать картинку и переименовать;
- понимать, где лежит папка проекта.

## Пошаговое задание



### Шаг 1. Своя копия курса

Инструкция с кнопками — **в браузере**, в корневом [README.md](../../README.md) репозитория группы.

1. Зарегистрируйся на github.com (логин латиницей, подтверди почту).
2. Открой репозиторий **своей группы** (ссылку даёт преподаватель).
3. **Fork**.
4. Открой программу **Терминал** (Spotlight: `Terminal`). VS Code сегодня не нужен.
5. `git clone` **своего форка** (в репозитории зелёная Code → HTTPS):

```bash
git clone https://github.com/ТВОЙ_ЛОГИН/js40-group-….git
cd js40-group-…
```

Запомни эту папку на диске. Дальше команды `git` — из неё.

Дальше все файлы — внутри этого клона, не на рабочем столе, не в отдельной папке.

### Шаг 2. Первый файл

1. Открой папку `lessons/01-files-folders-browser/` (там этот README).
2. Создай рядом файл `my-first-note.txt` со строкой:
  `Сегодня я начинаю путь в веб-музыке!`



### Шаг 3. Браузер

1. Открой браузер, в адресной строке: `https://example.com`.
2. Новая вкладка, закрыть вкладку, меню загрузок (Downloads).



### Шаг 4. Картинка

1. Скачай небольшую картинку (ссылка преподавателя или любая: ноты, гитара).
2. Правая кнопка мыши → «Сохранить изображение как…».
3. Перенеси файл в `lessons/01-files-folders-browser/`.
4. Имя латиницей: `guitar.png` или `notes.jpg`.

Нет ссылки — Wikimedia Commons, сразу переименуй.

### Шаг 5. Копирование

Файл `my-first-note.txt` ты создал(а) на шаге 2 в папке этого урока. Скачивать его не нужно.

1. Открой `my-first-note.txt`.
2. Выдели всё (Ctrl+A / Cmd+A), скопируй (Ctrl+C / Cmd+C).
3. В той же папке создай `note-copy.txt` и вставь (Ctrl+V / Cmd+V).
4. Добавь строку: `Копирование работает!`

Если файла нет — вернись к шагу 2.

### Шаг 6. Страница в браузере

1. В той же папке урока создай `hello.html`.
2. Вставь **целиком** (разберём на уроке 4):

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Привет, музыка!</title>
</head>
<body>
  <h1>Привет, мир музыки!</h1>
  <p>Это моя первая страница.</p>
</body>
</html>
```

1. Сохрани. Открой `hello.html` двойным щелчком в браузере.



### Шаг 7. Commit и push

Редактор кода ещё не открывали. Команды — в том же **Терминале**, в папке клона (если закрыл окно: снова Terminal и `cd` в папку с шага 1).

```bash
git checkout -b lesson-01
git add .
git commit -m "урок 01: файлы и браузер"
git push -u origin lesson-01
```

На github.com в **своём форке** открой ту же папку — файлы на месте. Затем Pull Request в группу: заголовок `урок 01 — Имя Фамилия`. Правила — в корневом [README.md](../../README.md). Merge не нажимай.

## Типичные ошибки


| Ошибка                               | Что делать                            |
| ------------------------------------ | ------------------------------------- |
| Клонировал репозиторий преподавателя | Clone свой URL: в адресе твой логин   |
| Создал папку на рабочем столе        | Работаем в клоне, в папке этого урока |
| Не вижу скачанный файл               | Папка «Загрузки»                      |
| `.html` открылся в редакторе         | Правая кнопка мыши → браузер          |
| Склонировал репозиторий группы       | Clone свой форк: в URL твой логин     |
| `git status` ничего не показывает    | Файлы не сохранены; команды не из папки клона |
