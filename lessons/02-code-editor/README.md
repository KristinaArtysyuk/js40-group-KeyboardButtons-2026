# Урок 02. Редактор кода

Сегодня редактор кода. Программа пишет в **консоль** и на страницу. Всплывающие окна (`alert`) в работах курса не нужны.

Рабочая копия — **тот же** клонированный репозиторий, что на уроке 1. Слова — в [README.md](../../README.md).

## Цели

- открыть папку репозитория в VS Code;
- дописать `lessons/02-code-editor/starter/`;
- подключить JavaScript;
- увидеть текст на странице и в консоли (F12);
- сделать commit и push.

## Что понадобится

- Свой репозиторий с урока 1 (clone на диске)
- VS Code (рекомендуется)
- Браузер, Git

## Пошаговое задание

### Шаг 1. Открой репозиторий в редакторе

1. VS Code → **File → Open Folder**.
2. Выбери **корень** своего клона — слева дерево `lessons/` и остальные папки курса.

### Шаг 2. Открой starter этого урока

1. Папка `lessons/02-code-editor/starter/`.
2. Открой `index.html`. Пока только разметка. Дальше правишь **эти** файлы.

### Шаг 3. Добавь скрипт

1. В `starter` создай `script.js` (если файла ещё нет).
2. Впиши:

```js
// Комментарий: приветствие в консоли и на странице
console.log("Привет, мир музыки!");

document.getElementById("hello").textContent = "Привет, мир музыки!";
```

3. В `index.html` перед `</body>` добавь:

```html
<script src="script.js"></script>
```

4. Сохрани оба файла (Ctrl+S / Cmd+S).

### Шаг 4. Браузер

1. Открой `lessons/02-code-editor/starter/index.html` в браузере.
2. На странице — текст приветствия.
3. F12 (на Mac часто Cmd+Option+I) → Console — та же фраза.

HTML — разметка. JavaScript — программа. Консоль — `console.log` и красные ошибки.

### Шаг 5. Commit и push

```bash
git add .
git commit -m "урок 02: редактор и консоль"
git push
```

На github.com в той же папке `starter` должен быть `script.js`.

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| На странице пусто | `id="hello"`, скрипт перед `</body>` |
| Консоль пустая | Сохрани, обнови страницу, вкладка Console |
| `script.js` не в той папке | Рядом с `index.html` в `starter` |
| Точка на вкладке файла | Ctrl+S / Cmd+S |
