# Урок 03. GitHub: commit, push, README

Репозиторий и clone уже должны быть с урока 1. Сегодня закрепляем слова, оформляем README своего репозитория и проверяем работы уроков 1–2 **на GitHub**.

Как взять материалы и слова — в [README.md](../../README.md).

Сдача — Pull Request в репозиторий **группы**. Merge не нажимаем.

## Цели

- объяснить clone, commit, push своими словами;
- заполнить README своего репозитория: имя и инструмент;
- проверить на github.com файлы уроков 1 и 2;
- отличить файлы на диске от копии после push.

## Что понадобится

- Свой репозиторий с уроков 1–2
- Браузер, Git
- `lessons/03-github-account/starter/README.md` — текст для копирования

## Пошаговое задание

### Шаг 1. Если репозитория ещё нет

Пройди [README.md](../../README.md): аккаунт → Fork группы → clone своего форка. Сделай задания уроков 1–2 в их папках, push и Pull Request в группу.

### Шаг 2. Слова

| Слово | Значение |
|--------|----------|
| Репозиторий (repo) | Папка проекта на GitHub |
| Clone | Копия репозитория на компьютере |
| Commit | Сохранённая версия с комментарием |
| Push | Отправка commit на GitHub |
| README.md | Файл: о чём проект и как открыть |
| Pull Request | Сдача в репозиторий группы. Merge не жмём |

### Шаг 3. README своего репозитория

1. Открой `lessons/03-github-account/starter/README.md`.
2. Заполни поля без квадратных скобок (имя, инструмент).
3. Скопируй текст в **корневой** `README.md` своего репозитория (VS Code или карандаш Edit на github.com).  
   Учебный README курса можно заменить своим или добавить раздел «Об авторе» сверху. Имя и инструмент должны быть видны сразу.
4. Commit: `docs: README — имя и инструмент`. Push.

Практичный вариант: оставь файл курса и добавь в начало несколько строк о себе.

### Шаг 4. Проверь уроки 1 и 2

На github.com в **своём** репозитории:

- `lessons/01-files-folders-browser/` — `hello.html` и заметки;
- `lessons/02-code-editor/starter/` — `index.html` и рабочий `script.js`.

Если на сайте старые файлы: `git add .` → `git commit` → `git push`.

## Критерии сдачи

- [ ] Можешь сказать: clone — на диск, commit — версия, push — на GitHub
- [ ] В README своего repo видны имя и инструмент
- [ ] На github.com видны работы уроков 1 и 2
- [ ] Есть Pull Request уроков 1–2 в репозиторий группы, без merge

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| PR в js-music-course-40h | Закрой. Сдаём в репозиторий **группы** |
| 2FA / пароль | Почта; иначе преподаватель |
| README только шаблон курса | Добавь имя и инструмент |
| Файлы есть на диске, нет на сайте | Push |
