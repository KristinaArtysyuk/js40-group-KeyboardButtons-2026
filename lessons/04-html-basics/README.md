# Урок 04. Основы HTML

Сегодня собираем первую афишу на HTML: заголовок, текст, кнопка и картинка. HTML задаёт структуру страницы. Потом добавим оформление (CSS) и поведение (JavaScript).

## Цели

К концу урока ты сможешь:

- создать простую HTML-страницу с заголовком и абзацем;
- добавить кнопку и заглушку для изображения;
- подключить лёгкий CSS-файл;
- открыть страницу в браузере без сервера и без сборщиков.

## Что понадобится

- Свой клонированный репозиторий
- Редактор, браузер, Git
- Знания из уроков 01–03

## Пошаговое задание

### Шаг 1. Открой starter

1. Папка `lessons/04-html-basics/starter/`.
2. Открой `index.html` в редакторе и в браузере.
3. Там минимальный каркас: html, head, body. Страница почти пустая. Правишь файлы в этой папке.

### Шаг 2. Добавь афишу

Внутри body добавь:

1. Заголовок h1 — название вымышленного концерта.
2. Абзац p — дата, место или короткое описание.
3. Кнопку button — например, «Купить билет» (пока без действия).
4. Картинку: положи файл (например `poster.jpg`) **в ту же папку**, что и `index.html`, и напиши `src="poster.jpg"` и короткий `alt`. Интернет для картинки не обязателен.

### Шаг 3. Подключи стили

HTML — что на странице. CSS — как это выглядит. Правила пишешь ты в файле `style.css`.

В HTML ты уже написал теги: `<h1>`, `<button>`, `<body>`. В CSS браузеру нужно сказать, **какой тег** красить. Имя тега без `<` и `>` пишут перед фигурными скобками. Это и есть **селектор**: «к кому относится правило».

```css
h1 {
  font-size: 28px;
}
```

Здесь `h1` — селектор: «все заголовки h1 на странице». Внутри скобок — пары `свойство: значение;`. Двоеточие после свойства, точка с запятой в конце строки. Без скобок правило не работает.

| Свойство | Зачем | Пример значения |
|----------|--------|-----------------|
| `background` | цвет фона | `beige`, `#f4f0e8` |
| `font-family` | шрифт | `Georgia, serif`, `Arial, sans-serif` |
| `font-size` | размер текста | `28px`, `18px` |
| `padding` | отступ внутри | `24px`, `8px 16px` |
| `color` | цвет текста | `#222`, `navy` |

1. Создай `style.css` **в той же папке**, что `index.html`.
2. Напиши три правила: селекторы `body`, `h1` и `button` (те же имена, что теги в HTML). Значения выбери сам.
3. В `head` у `index.html` (вместо TODO) подключи файл — без этой строки браузер CSS не читает:

```html
<link rel="stylesheet" href="style.css">
```

`href="style.css"` — имя файла рядом с HTML.

4. Сохрани оба файла, обнови страницу (F5). Вид изменится только если правила написаны **и** есть `link`. Если всё как было — нет `link`, опечатка в имени или файлы не в одной папке.

Подробнее про цвета и отступы — урок 5.

### Шаг 4. Проверь в браузере

Открой свой `index.html`. Если застрял — F12 и скриншот преподавателю.

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| Стили не применяются | Проверь путь к style.css и что файл рядом с HTML |
| Картинка не видна | Файл должен лежать рядом с HTML; имя в `src` — точь-в-точь как у файла |
| Кириллица ломается | Оставь meta charset UTF-8 |
| Забыл закрыть тег | Проверь пары открывающих и закрывающих тегов |
| Правишь не тот файл | Работай в `lessons/04-html-basics/starter/` |
