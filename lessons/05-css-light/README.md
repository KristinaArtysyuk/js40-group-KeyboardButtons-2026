# Урок 05. Лёгкий CSS — афиша концерта

CSS задаёт внешний вид: цвет фона, размер шрифта, отступы. Сегодня оформляем афишу концерта.

## Цели

К концу урока ты сможешь:

- менять цвета текста и фона;
- задавать размеры шрифтов и отступы;
- оформить карточку-афишу;
- сравнить страницу до и после правок и объяснить, что изменилось визуально.

## Что понадобится

- Редактор кода и браузер
- Папка `05-css-light`
- HTML из предыдущего урока (понятие тегов)

## Пошаговое задание

### Шаг 1. Открой starter

1. Открой `starter/index.html` и `starter/style.css` в редакторе.
2. Открой HTML в браузере — базовая афиша уже есть, но выглядит скромно.

### Шаг 2. Усиль настроение

В `style.css` попробуй:

1. Сменить `background` у `body` на более «концертный» цвет (тёмный или яркий).
2. Увеличить `font-size` у заголовка.
3. Добавить `padding` и `border-radius` блоку афиши.
4. Сделать кнопку контрастной (яркий фон, светлый текст).

### Шаг 3. Сделай афишу своей

Не копируй чужой файл. Измени название концерта и палитру под свой жанр. Если застрял — F12 и скриншот преподавателю.

### Шаг 4. Проверь в браузере

Обновляй страницу после каждого сохранения (F5). Смотри, как меняются цвет и размер.

## Критерии сдачи

- [ ] Страница открывается локально в браузере
- [ ] Есть заметные отличия от исходного starter: цвета и размеры
- [ ] Афиша выглядит как карточка (отступы / фон / скругления)
- [ ] Кнопка визуально выделена
- [ ] Комментарии в CSS на русском

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| Правки в CSS не видны | Сохрани файл и жёстко обнови страницу (Ctrl+F5) |
| Слишком мелкий текст | Увеличь font-size у h1 и p |
| Низкий контраст | Тёмный текст на тёмном фоне — плохо; проверь читаемость |
| Сломал HTML, правя CSS | CSS не удаляет теги; проверь, что правишь нужный файл |
| Забыл селектор | Имена в CSS должны совпадать с тегами/классами в HTML |

## Домашнее задание

**Must** — обязательно

1. Класс `.poster` у блока афиши **уже есть** в starter. Не добавляй второй такой же — усили его: своя палитра (2–3 цвета) под любимый жанр.
2. Напиши в заметке: какие три свойства CSS сильнее всего изменили вид страницы?

**Stretch** — если Must готов: отдельный класс для кнопки, например `.ticket`.

Дальше — JavaScript: кнопка на афише оживёт, сменит текст с цветом и сыграет ля.
