# Урок 06. Подключаем JavaScript и первую ноту

HTML — структура, CSS — оформление, JavaScript — поведение. Сегодня кнопка меняет текст и цвет **и издаёт ля (440 Гц)**. Это первый слышимый результат курса.

## Цели

К концу урока ты сможешь:

- подключить файл `script.js`;
- найти кнопку и повесить клик;
- изменить текст и цвет;
- вызвать готовую команду playA4() — браузер сыграет ля;
- смотреть ошибки в консоли (F12).

DOM (поиск элементов на странице) мы уже **используем**. Как он устроен — разберём на уроке 13. Сегодня достаточно: нашёл кнопку → по клику что-то сделал.

## Где какой файл

| Файл | Зачем | Сегодня |
|------|--------|---------|
| `index.html` | Кнопки и абзац на странице | Проверь, что есть `<script src="script.js"></script>`. Теги кнопок не переписывай. |
| `style.css` | Вид страницы при открытии | **Не трогай.** Цвет по нажатию пишется не сюда. |
| `script.js` | Что происходит после нажатия | **Сюда пишешь задание** — под комментариями `TODO`, ниже готовой `playA4`. |

`style.background` в JavaScript — это не файл стилей. Это команда в `script.js`: «покрась эту кнопку сейчас».

## Пошаговое задание

### Шаг 1. Открой starter

1. Папка `lessons/06-js-connect/starter/`.
2. Открой `index.html` в браузере: кнопки есть, пока ничего не делают.
3. Открой `script.js`: сверху уже есть `playA4` — её не переписывай.

### Шаг 2. Подключи скрипт

В `index.html` перед `</body>` должна быть строка (если есть — не дублируй):

```html
<script src="script.js"></script>
```

### Шаг 3. Примеры (это ещё не задание)

Читаешь. В свой `script.js` отсюда ничего не копируй целиком.

**Вызвать функцию** — имя и скобки. Без скобок команда не запускается.

```js
function sayHello() {
  console.log("привет");
}

sayHello;   // ничего
sayHello(); // в консоли «привет»
```

`playA4` такая же: звук уже внутри. Пишешь `playA4()`, тело функции не копируешь.

**Сменить текст** — в HTML абзац уже есть:

```html
<p id="status">Тишина… нажми Play или сыграй ля</p>
```

В `script.js` (не в HTML и не в CSS):

```js
const status = document.querySelector("#status");
status.textContent = "Идёт запись";
```

`#status` — тот же `id`, решётка обязательна. Справа от `=` — новая фраза на странице.

Не из задания, тот же приём: если бы был `<p id="clock">12:00</p>`:

```js
document.querySelector("#clock").textContent = "12:01";
```

**После нажатия, не сразу.** Код между `{` и `}` у `addEventListener` ждёт нажатие.

```js
кнопка.addEventListener("click", function () {
  // сюда — только то, что после нажатия
});
```

Что выше или ниже этих скобок — сработает при открытии страницы. Звук браузер даёт только после нажатия.

### Шаг 4. Задание: оживи кнопки

Пиши **только в `script.js`**, под строками `TODO`. `style.css` не открывай. `index.html` не меняй, кроме шага 2.

1. `querySelector` для `#playBtn` и `#status`.
2. У `#playBtn` — `addEventListener`, как в примере шага 3.
3. Между `{` и `}` этой кнопки: новый `textContent` у статуса и `playBtn.style.background = "tomato";` (цвет свой). Это JavaScript, не CSS-файл.
4. `querySelector` для `#toneBtn`. Свой `addEventListener`. Между `{` и `}` этой кнопки: `playA4()`.

### Шаг 5. Проверь

- Play меняет текст/цвет.
- «Сыграть ля» слышна нота.
- В консоли нет красных ошибок.

Если тишина: громкость, наушники, клик именно по кнопке ноты, F12.

## Типичные ошибки


| Ошибка                  | Что делать                                    |
| ----------------------- | --------------------------------------------- |
| Клик молчит             | F12 — часто опечатка в id                     |
| `null` у querySelector  | Сверь `#playBtn` / `#toneBtn` с HTML          |
| Звука нет               | `playA4()` — между `{` и `}` у кнопки «Сыграть ля», не в начале файла |
| Скрипт сработал до HTML | `<script>` в конце `body`                     |
