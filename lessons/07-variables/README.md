# Урок 07. Переменные

Переменная хранит значение под именем: один раз записал, дальше используешь это имя в коде.

## Цели

К концу урока ты сможешь:

- объявлять переменные через `let` и `const`;
- хранить числа и строки;
- собирать текст через шаблонные строки (`` `...${...}` ``);
- вывести на страницу название песни и исполнителя из переменных.

## Что понадобится

- Всё из уроков 01–06
- Браузер и редактор кода
- Папка `07-variables/starter`

## Тайминг (~2 ч)

|------|-------|

## Пошаговое задание

### Шаг 1. Открой starter

1. Открой `starter/index.html` в редакторе и в браузере.
2. На странице — карточка трека и кнопка **Показать карточку**.
3. Пока кнопка почти ничего не делает — это твоя задача.

### Шаг 2. Создай переменные

В `starter/script.js` объяви:

```js
// Название трека (строка)
let songTitle = "Лунная соната";

// Исполнитель / композитор (строка)
let artist = "Людвиг ван Бетховен";

// Год (число)
let year = 1801;

// Жанр
const genre = "Классика";
```

> `const` — значение, которое не планируешь менять. `let` — если значение может измениться.

### Шаг 3. Шаблонная строка

Собери текст карточки:

```js
let cardText = `🎵 ${songTitle}
Исполнитель: ${artist}
Год: ${year}
Жанр: ${genre}`;
```

### Шаг 4. Выведи на страницу

По клику на кнопку запиши текст в элемент `#card-text` и заполни поля `#title`, `#artist`:

```js
document.getElementById("card-text").textContent = cardText;
document.getElementById("title").textContent = songTitle;
document.getElementById("artist").textContent = artist;
```

### Шаг 5. Проверь в браузере

Карточка должна заполниться по кнопке. Если застрял — F12 и скриншот преподавателю.

## Критерии сдачи

- [ ] Есть переменные для названия, исполнителя, года (и желательно жанра)
- [ ] Используется хотя бы одна шаблонная строка с `${...}`
- [ ] По кнопке на странице появляются название и исполнитель
- [ ] Комментарии в коде на русском
- [ ] Страница открывается двойным кликом по `index.html` (без сервера)

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| `Unexpected string` / странная ошибка в шаблоне | Нужны обратные кавычки `` ` ``, не обычные `' '` или `" "` |
| На странице пусто | Проверь `id` элементов и что скрипт подключён перед `</body>` |
| `songTitle is not defined` | Объяви переменную до использования |
| Путаешь `=` и `==` | Для записи в переменную нужен один знак `=` |
| Кириллица «кракозябрами» | Файл в UTF-8, в HTML есть `<meta charset="UTF-8">` |

## ДЗ

**Must**

1. Поменяй переменные на свою любимую песню и исполнителя.
2. Добавь переменную `duration` (длительность в секундах, число) и выведи её в карточке.

**Stretch:** вторая карточка (другие переменные + второй блок на странице) — или опиши в заметке, как бы ты это сделал.

На следующем уроке — **if / else**: в коде выбираем, какую ветку выполнить.
