# Урок 08. Условия if / else

`if` и `else` выбирают, какой код выполнить: условие истинно — одна ветка, иначе — другая.

В starter уже есть **список нот** в квадратных скобках: `["До", "Ре", …]`. Это массив. Сегодня просто берём из него ноту. Как устроен массив — урок 11.

## Цели

К концу урока ты сможешь:

- писать условия с `if` / `else` (и при желании `else if`);
- сравнивать строки и числа (`===`, `!==`);
- сделать мини-игру «Угадай ноту» или музыкальный квиз true/false;
- показывать разный текст в зависимости от ответа.

## Что понадобится

- Уроки 01–07 (особенно переменные)
- Браузер и редактор
- Папка `08-if-else/starter`

## Пошаговое задание

### Шаг 1. Открой игру

1. Открой `starter/index.html` в браузере.
2. Есть поле ввода, кнопка **Проверить** и блок результата.
3. Секретная нота уже загадана в `script.js` — тебе нужно дописать проверку.

### Шаг 2. Прочитай загадку

В скрипте есть список нот `notes` (массив, разберём на уроке 11) и переменная `secretNote`. Пользователь вводит ответ в поле `#guess`.

### Шаг 3. Допиши `script.js`

Кнопки уже подключены. Случайная нота при старте уже есть. Твоё — тела функций.

- `pickNewNote` — новая нота из `notes`, сброс попыток и поля. Кнопка «Новая нота» вызывает эту функцию.
- Клик «Проверить»: пустое поле → `return`; иначе счётчик; `if (guess === secretNote)` / `else` с разным текстом и `className` (`"result ok"` / `"result bad"` — стили из `style.css`).

### Шаг 6. Проверь в браузере

Верный и неверный ответ должны давать разный текст. Если застрял — F12.

## Критерии сдачи

- [ ] Есть рабочий `if` / `else` при проверке ответа
- [ ] При верном ответе — понятное «Правильно», при неверном — «Неправильно…»
- [ ] Сравнение через `===` (не присваивание `=`)
- [ ] Комментарии на русском
- [ ] Открывается через `index.html` без сервера

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| Всегда «неправильно», хотя вроде верно | Проверь регистр и пробелы; используй `.trim()`; сравнивай с той же строкой («До», не «до») |
| Написал `if (guess = secretNote)` | Нужно `===`, один `=` записывает значение |
| Результат не меняется | Проверь `id` и что обработчик клика повешен на кнопку |
| `secretNote` не меняется | Для новой игры снова выбери элемент из массива |

## Домашнее задание

**Must:** рабочий `if` / `else` в игре «угадай ноту» — верно и неверно видно на странице.

**Stretch:** подсказка после 3 неверных попыток. Случайную новую ноту можно взять из подсказки в `script.js` (`Math.random` подробно будет на уроке 11).

Дальше — **циклы**: повторять действие несколько раз.
