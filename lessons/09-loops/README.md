# Урок 09. Циклы

Цикл `for` или `while` повторяет одно и то же действие, пока выполняется условие. Так можно вывести весь список, не копируя строки вручную.

Список `tracks` в starter — снова массив. Цикл ходит по нему по номерам (`0`, `1`, `2`…). Сами массивы разберём на уроке 11; сегодня важен повтор.

## Цели

К концу урока ты сможешь:

- пройтись по массиву треков циклом `for`;
- повторить действие N раз циклом `while`;
- вывести нумерованный список песен на страницу;
- понять, зачем нужны счётчик и условие выхода.

## Что понадобится

- Уроки 01–08
- Браузер и редактор
- Папка `09-loops/starter`

## Пошаговое задание

### Шаг 1. Открой starter

1. Открой `starter/index.html` в браузере.
2. Есть список `#track-list`, счётчик `#count`, кнопка **Показать плейлист**.
3. Ниже — поле `#repeat-count` и кнопка **Повторить** для «Бис!».
4. В `script.js` уже есть массив `tracks` и ссылки на элементы. Тела функций — твоя задача.

### Шаг 2. Функция `renderPlaylist`

Собери отрисовку плейлиста в одну функцию — её вызовут и кнопка, и загрузка страницы.

Внутри `renderPlaylist`:

1. Очисти список, чтобы при повторном нажатии треки не дублировались: `listEl.innerHTML = ""`.
2. Циклом `for` пройди все индексы массива и добавь пункты в `#track-list`:

```js
for (let i = 0; i < tracks.length; i = i + 1) {
  let li = document.createElement("li");
  li.textContent = (i + 1) + ". " + tracks[i];
  listEl.appendChild(li);
}
```

3. Обнови счётчик: `countEl.textContent = "Треков: " + tracks.length`.

Кнопка `#show-btn` уже должна вызывать `renderPlaylist` (без своей анонимной функции). В конце файла вызови `renderPlaylist()` ещё раз — плейлист появится сразу при открытии страницы.

### Шаг 3. Повтор «Бис!» циклом `while`

По клику **Повторить** число уже читается из `#repeat-count` в переменную `n`.

- Если число пустое или меньше 1 (`!n || n < 1`) — напиши в `#bis-box`: `Укажи число от 1 и больше.` и сделай `return`.
- Иначе собери текст циклом `while`: счётчик `k` от 1 до `n`, каждая строка вида `👏 Бис! × 1`.
- Запиши результат в `bisBox.textContent` (лишний перевод строки в конце можно убрать через `.trim()`).

```js
let lines = "";
let k = 1;
while (k <= n) {
  lines = lines + "👏 Бис! × " + k + "\n";
  k = k + 1;
}
bisBox.textContent = lines.trim();
```

### Шаг 4. Проверь в браузере

При открытии страницы плейлист уже на экране, кнопка перерисовывает его без дублей. «Повторить» печатает N строк «Бис!». Если застрял — F12.

## Критерии сдачи

- [ ] Плейлист выводится циклом `for` (не вручную несколько `appendChild`)
- [ ] Текст пункта: номер, точка, название (`1. Лунная соната`)
- [ ] Счётчик показывает `Треков: ` и `tracks.length`
- [ ] «Бис!» повторяется циклом `while` столько раз, сколько в поле
- [ ] Пустое или неверное число даёт сообщение, а не бесконечный цикл
- [ ] Комментарии на русском
- [ ] Работает открытием `index.html`

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| Бесконечный цикл (вкладка зависла) | Проверь, что счётчик увеличивается; условие должно стать ложным |
| Список дублируется | Перед циклом сделай `listEl.innerHTML = ""` |
| `i <= tracks.length` | Нужно `i < tracks.length` (индексы с 0) |
| Пустой список | Убедись, что `renderPlaylist()` вызывается и массив не пустой |
| «Бис!» не печатается | Проверь `while (k <= n)` и что `k = k + 1` внутри цикла |
