# Урок 10. Функции

Функция — именованный фрагмент кода: один раз написал `formatTrack`, потом вызываешь сколько нужно.

## Цели

К концу урока ты сможешь:

- объявлять свои функции с параметрами;
- возвращать значение через `return`;
- написать `formatTrack`, `greet`, `bpmToTempo` и `randomNote`;
- менять текст на странице вызовом функции по кнопке.

## Что понадобится

- Уроки 01–09
- Браузер и редактор
- Папка `10-functions/starter`

## Пошаговое задание

### Шаг 1. Открой «Музыкальный помощник»

1. Открой `starter/index.html` в браузере.
2. Есть поля названия, исполнителя, имени и BPM — и четыре кнопки.
3. Результат появляется в `#output`. Каркас функций уже есть в `script.js` — допиши `return` и вызовы.

### Шаг 2. `formatTrack(title, artist)`

Верни строку «название — исполнитель»:

```js
function formatTrack(title, artist) {
  return `${title} — ${artist}`;
}
```

По клику **formatTrack** значения уже читаются из `#title-input` и `#artist-input`. Запиши в `#output`:

```js
outputEl.textContent = formatTrack(title, artist);
```

### Шаг 3. `greet(name)`

Верни приветствие и покажи его по кнопке **greet**:

```js
function greet(name) {
  return `Привет, ${name}! Готов к джему? 🎸`;
}
```

```js
outputEl.textContent = greet(name);
```

### Шаг 4. `bpmToTempo(bpm)`

По числу BPM верни словесный темп:

| BPM | Текст |
|-----|--------|
| меньше 60 | `Largo (очень медленно)` |
| меньше 80 | `Adagio (медленно)` |
| меньше 100 | `Andante (спокойным шагом)` |
| меньше 120 | `Moderato (умеренно)` |
| меньше 160 | `Allegro (быстро)` |
| иначе | `Presto (очень быстро)` |

Цепочка `if` / `else if` / `else`. По кнопке **bpmToTempo** покажи и число, и слово:

```js
outputEl.textContent = bpm + " BPM → " + bpmToTempo(bpm);
```

### Шаг 5. `randomNote()`

Список нот уже есть внутри функции. Выбери случайный индекс и верни ноту:

```js
let index = Math.floor(Math.random() * notes.length);
return notes[index];
```

По кнопке **randomNote**:

```js
outputEl.textContent = "Случайная нота: " + randomNote();
```

`Math.random` подробно будет на уроке 11 — сегодня достаточно скопировать формулу.

### Шаг 6. Проверь в браузере

Каждая кнопка должна показать результат своей функции. Если застрял — F12.

## Критерии сдачи

- [ ] `formatTrack(title, artist)` возвращает строку через `return`
- [ ] `greet(name)` возвращает приветствие
- [ ] `bpmToTempo(bpm)` выбирает темп через `if` / `else if`
- [ ] `randomNote()` возвращает случайную ноту из списка
- [ ] Каждая кнопка записывает результат в `#output`
- [ ] Комментарии на русском
- [ ] Работает через открытие `index.html`

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| Функция «ничего не делает» | Нужен `return` или явное изменение DOM внутри |
| `formatTrack is not defined` | Объяви функцию до вызова (или используй `function` declaration) |
| На экране `undefined` | Забыл `return` |
| Параметры и поля перепутаны | Проверь порядок аргументов: `(title, artist)` |
| Темп всегда один и тот же | Проверь пороги `< 60`, `< 80`… и ветку `else` |
