# Урок 11. Массивы

Массив — упорядоченный список. Сегодня в массиве храним названия треков и выводим плейлист на страницу: добавить, показать все, выбрать случайный.

## Цели

К концу урока ты сможешь:

- создавать массив и читать элементы по индексу;
- добавлять элемент через `push`;
- показывать весь плейлист на странице;
- выбирать случайный трек (`Math.random` + индекс);
- собрать рабочий мини-UI плейлиста.

## Что понадобится

- Уроки 01–10 (особенно циклы и функции)
- Браузер и редактор
- Папка `11-arrays/starter`

Этот урок — **1 час**, в одной паре с уроком 12 (см. [PROGRAM.md](../../PROGRAM.md)). Список нот на уроках 8–10 уже был массивом; сегодня разбираем его отдельно.

## Пошаговое задание

### Шаг 1. Открой плейлист

В starter есть поле ввода и кнопки **Добавить**, **Показать все**, **Случайный трек**. Массив `playlist` уже объявлен.

### Шаг 2. Функция showAll

Циклом отрисуй все элементы массива в `#playlist` и обнови счётчик `#count`.

### Шаг 3. Добавление

По **Добавить**: возьми текст из `#song-input`, если не пустой — `playlist.push(song)`, очисти поле, вызови `showAll`.

### Шаг 4. Случайный трек

```js
let index = Math.floor(Math.random() * playlist.length);
let track = playlist[index];
```

Покажи трек в `#random-box`. Если плейлист пуст — сообщи об этом.

### Шаг 5. (По желанию) Удалить последний

`playlist.pop()` и снова `showAll`.

### Шаг 6. Проверь в браузере

Добавление, список и случайный трек должны работать без сервера. Если застрял — F12.

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| Добавил, но список не обновился | После `push` вызови отрисовку снова |
| Случайный всегда один и тот же | Не хардкодь индекс; считай от `playlist.length` |
| `Cannot read properties of undefined` | Проверь, что массив не пустой перед выбором |
| Пустые строки в списке | Не делай `push`, если `trim()` дал `""` |
