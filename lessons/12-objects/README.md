# Урок 12. Объекты

Объект хранит несколько полей под одним именем. Сегодня поля — `title`, `artist`, `bpm`, `genre`.

## Цели

К концу урока ты сможешь:

- создавать объекты с полями title, artist, bpm;
- хранить несколько карточек в массиве;
- читать свойства через точку;
- рисовать карточки на странице;
- добавлять новую песню из формы.

## Что понадобится

- Уроки 07–11
- Браузер и редактор
- Папка `12-objects/starter`

Этот урок — **1 час**, в одной паре с уроком 11 (см. [PROGRAM.md](../../PROGRAM.md)).

## Пошаговое задание

### Шаг 1. Открой starter

Открой `starter/index.html` — форма «Новая песня» и каталог. В `script.js` уже есть один объект `example` и массив `songs`.

### Шаг 2. Массив объектов

Допиши в `songs` ещё 4 песни (всего 5) с полями `title`, `artist`, `bpm`, `genre`. Читай поля через точку: `song.title`, `song.bpm`.

### Шаг 3. Функция `tempoName(bpm)`

По BPM верни название по шкале курса (её же используем в метрономе на уроке 16):

| BPM | Темп |
|-----|------|
| меньше 60 | Largo |
| меньше 76 | Adagio |
| меньше 108 | Andante |
| меньше 120 | Moderato |
| меньше 168 | Allegro |
| меньше 200 | Presto |
| иначе | Prestissimo |

Число **120** — уже Allegro, не Moderato.

### Шаг 4. Отрисуй карточки в `renderSongs`

Каталог уже очищается, счётчик уже обновляется. В цикле `for` по `songs` создай карточку:

```js
let card = document.createElement("article");
card.className = "song-card";
```

Внутри карточки (через `innerHTML` или отдельные элементы):

- `h2` — название;
- `p` с классом `meta` — исполнитель;
- `p` с классом `meta` — `BPM: число · tempoName`;
- `span` с классом `badge` — жанр.

Добавь карточку в `#catalog` через `appendChild`.

### Шаг 5. Добавление из формы

По кнопке **Добавить**:

1. Прочитай `#title`, `#artist`, `#bpm`, `#genre` (`trim`, BPM через `Number`).
2. Если жанр пустой — подставь `"Разное"`.
3. Если нет названия, исполнителя или BPM — `alert("Заполни название, исполнителя и BPM")` и `return`.
4. `songs.push({ title: title, artist: artist, bpm: bpm, genre: genre })`.
5. Вызови `renderSongs()` и очисти поля.

У кнопки уже `type="button"`, иначе страница перезагрузится.

### Шаг 6. Проверь в браузере

Пять карточек на экране, форма добавляет шестую. Если застрял — F12.

## Критерии сдачи

- [ ] Массив из 5 объектов с полями title, artist, bpm, genre
- [ ] Карточки на странице через `renderSongs`
- [ ] Добавление из формы (`push` + повторная отрисовка)
- [ ] BPM с названием темпа на карточке
- [ ] Комментарии на русском

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| `undefined` у свойства | Проверь имя поля |
| Нет карточек | Вызови отрисовку после изменения массива |
| Страница обновляется | `type="button"` у кнопки |
| BPM как строка | `Number(...)` |
| Жанр пустой | Подставь `"Разное"`, если поле не заполнили |
