# Урок 13. DOM

С урока 6 мы уже ищем кнопки и меняем текст. Сегодня называем это **DOM**: дерево элементов страницы. Ты находишь элемент и меняешь текст, класс или стиль по клику.

## Цели

К концу урока ты сможешь:

- находить элементы через `getElementById` и `querySelector`;
- менять `textContent`;
- добавлять и снимать классы (`classList`);
- вешать `addEventListener`;
- создавать элементы и добавлять их на страницу.

## Что понадобится

- Уроки 07–12
- Браузер и редактор
- Папка `13-dom/starter`

## Пошаговое задание

### Шаг 1. Открой starter

Открой `starter/index.html` — концертная афиша с кнопками. В `script.js` элементы уже найдены: `poster`, `titleEl`, `dateEl`, `venueEl`, `artists`.

### Шаг 2. Смена текста

По клику запиши `textContent`:

| Кнопка | Текст |
|--------|--------|
| **Сменить название** | `Ночь джаза и импровизации` |
| **Сменить дату** | `Дата: 21 июня, 20:00` |
| **Сменить площадку** | `Площадка: Открытая сцена во дворе` |

### Шаг 3. Смена темы

Напиши функцию `setTheme(name)`: сними с `#poster` классы `theme-classical`, `theme-rock`, `theme-jazz` и добавь `name`.

По кнопкам темы вызови `setTheme` и поменяй заголовок:

| Кнопка | Класс | Заголовок |
|--------|--------|-----------|
| Тема: классика | `theme-classical` | `Вечер камерной музыки` |
| Тема: рок | `theme-rock` | `Рок-вечер выпускников` |
| Тема: джаз | `theme-jazz` | `Джазовый джем` |

```js
poster.classList.remove("theme-classical", "theme-rock", "theme-jazz");
poster.classList.add(name);
```

### Шаг 4. Новый артист

Список имён и счётчик уже есть в `script.js`. По кнопке **Добавить артиста**:

1. `document.createElement("div")`;
2. `className = "artist-card"`;
3. текст — `artistNames[artistIndex % artistNames.length]`;
4. увеличь `artistIndex`;
5. `artists.appendChild(card)`.

`%` возвращает к началу списка, когда имена закончатся.

### Шаг 5. Проверь в браузере

Текст и темы меняются, артисты появляются один за другим. Если застрял — F12.

## Критерии сдачи

- [ ] Поиск элементов работает
- [ ] Название, дата и площадка меняются по кнопкам
- [ ] Темы переключаются через `classList` (старый класс снимается)
- [ ] Новый `.artist-card` появляется по клику

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| `null` у элемента | Проверь `id` |
| Класс не меняется | Сначала `remove` всех `theme-*`, потом `add` |
| Клики молчат | Скрипт в конце `body`, F12 |
| Всегда один и тот же артист | Увеличь `artistIndex` после добавления |
