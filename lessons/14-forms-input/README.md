# Урок 14. Формы и фильтры

Фильтры работают вместе (логика И): текст, BPM и жанр. На странице остаются только записи, которые проходят все условия.

## Цели

К концу урока ты сможешь:

- читать значения input и select;
- фильтровать массив объектов по нескольким условиям;
- обновлять список при вводе (события input и change);
- сбрасывать фильтры кнопкой Reset.

## Что понадобится

- Уроки 07–13
- Браузер и редактор
- Папка `14-forms-input/starter`

## Пошаговое задание

### Шаг 1. Открой starter

В `script.js` уже есть каталог из 10 песен, функция `render` и обработчики полей. Допиши тело `applyFilters`.

### Шаг 2. Прочитай значения фильтров

Внутри `applyFilters`:

```js
let q = document.getElementById("q").value.trim().toLowerCase();
let maxBpm = Number(document.getElementById("bpm").value);
let genre = document.getElementById("genre").value;
```

Собери новый массив `result = []`.

### Шаг 3. Три условия (логика И)

Циклом по `songs` проверь каждую песню. В `result` попадают только те, у кого **все три** условия истинны:

| Фильтр | Условие |
|--------|---------|
| Текст | `q` пустой **или** `title` / `artist` содержит `q` (оба через `toLowerCase`, ищи через `indexOf`) |
| BPM | `s.bpm <= maxBpm` |
| Жанр | `genre` пустой **или** `s.genre === genre` |

```js
if (textOk && bpmOk && genreOk) {
  result.push(s);
}
```

В конце: `render(result)` — не `render(songs)`.

### Шаг 4. Сброс

Кнопка **Сбросить** в starter уже чистит поля и вызывает `applyFilters`. Когда фильтр написан, сброс сам покажет весь каталог.

### Шаг 5. Проверь фильтры

«Queen» оставляет «Богемская рапсодия». BPM 100 убирает быстрый джаз. Жанр «Рок» + текст работают вместе. Если застрял — F12.

## Критерии сдачи

- [ ] Текст, BPM и жанр фильтруют вместе (И)
- [ ] Список обновляется при изменении полей
- [ ] Кнопка сброса возвращает полный каталог
- [ ] Показано число найденных песен
- [ ] Страница открывается в браузере без сборки

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| Фильтры не вместе | Проверяй все условия в одном `if` |
| Регистр мешает | `toLowerCase` для сравнения |
| BPM сравнивается как строка | `Number(...)` |
| Пустой жанр | Пустое значение = любой жанр |
| Всегда все песни | Вызови `render(result)`, не `render(songs)` |
