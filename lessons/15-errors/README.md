# Урок 15. Ошибки и консоль

Ошибка в коде сначала видна в консоли, потом её исправляют. Сегодня учимся читать красный текст в F12.

## Цели

К концу урока ты сможешь:

- открыть консоль браузера (F12);
- читать сообщения об ошибках;
- пользоваться console.log для отладки;
- находить и исправлять типичные ошибки новичка.

## Консоль браузера

1. Открой страницу в браузере.
2. Нажми F12 (или Ctrl+Shift+I / Cmd+Option+I на Mac).
3. Вкладка Console — здесь ошибки и твои `console.log`.
4. Красный текст = ошибка. Кликни по ссылке справа — браузер покажет строку.

Пример отладки:

```
console.log("BPM =", bpm);
console.log("Список песен:", songs);
```

## Пошаговое задание

### Шаг 1. Открой starter

`starter/script.js` специально сломан — **6 багов**. Открой консоль. Красный текст — синтаксис и «переменная не найдена». Баг с `=` вместо `===` **не краснеет**: страница может «работать», но сравнение сломано. Его ищи по комментарию в файле.

### Шаг 2. Чини по одному

Над каждым багом есть комментарий. Исправь, обнови страницу (F5), смотри консоль. Когда все шесть пойманы, карточка заполнится: «Лунная соната», Бетховен, 60 BPM.

| Баг | Что сломано | Как должно стать |
|-----|-------------|------------------|
| 1 | Нет кавычек у строки | `let trackTitle = "Лунная соната"` |
| 2 | Опечатка `artsitName` | Пиши `artistName` |
| 3 | Нет `)` у `if` | `if (bpm > 0) {` |
| 4 | `=` вместо `===` | `if (genre === "Классика")` |
| 5 | Вызов `showTrackCard()` выше `const` | Сначала объяви функцию, потом вызови |
| 6 | `getElementById("titel")` | В HTML `id="title"` |

### Шаг 3. Кнопка «Проверить»

Когда страница работает — кнопка пишет «Успех! Все баги пойманы.» Если застрял — разбор с преподавателем, не копируй чужой файл целиком.

## Типичные ошибки новичков

| Ошибка | Пример | Как чинить |
|--------|--------|------------|
| Нет кавычек у строки | `let x = Привет` | `let x = "Привет"` |
| Опечатка в имени | `songTitlle` | Проверь имя переменной |
| Нет скобки | `if (x === 1` | Добавь `)` |
| `=` вместо `===` | `if (bpm = 120)` | Нужно `===`. Консоль может **не** покраснеть |
| Функция ещё не объявлена | вызов выше `const fn = function () {}` | Объяви функцию **выше** вызова |
| Неверный id | `getElementById("titel")` | Сверь с HTML |
