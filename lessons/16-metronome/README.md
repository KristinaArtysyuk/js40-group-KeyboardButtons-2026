# Урок 16. Метроном с кликом

Практичный метроном для занятий по специальности: BPM, старт/стоп, пульс и **слышимый клик**.

`playClick()` в starter уже готов — его писать не нужно. Твоя задача: интервал, BPM и название темпа.

## Цели

- собрать метроном на HTML + CSS + JS;
- `setInterval` / `clearInterval` и период `60000 / bpm`;
- вызвать готовый `playClick()` на каждый удар;
- показать название темпа по BPM.

## Что понадобится

- Уроки 07–15
- Наушники
- Папка `16-metronome/starter`

## Пошаговое задание

### Шаг 1. Открой starter

Открой `starter/index.html` в браузере. Кнопки есть, метроном пока не тикает. `playClick()` и `tick()` уже готовы — не удаляй вызов `playClick()` в `tick()`.

### Шаг 2. `tempoName(value)`

Верни название по шкале курса:

| BPM | Темп |
|-----|------|
| меньше 60 | Largo |
| меньше 76 | Adagio |
| меньше 108 | Andante |
| меньше 120 | Moderato |
| меньше 168 | Allegro |
| меньше 200 | Presto |
| иначе | Prestissimo |

**120 BPM — Allegro**, не Moderato: Moderato только пока число **строго меньше** 120.

### Шаг 3. `start()`

1. Если `timerId !== null` — останови старый интервал: `clearInterval(timerId)`.
2. `getAudioCtx()` уже вызывается (без клика по кнопке браузер может запретить звук).
3. Период в миллисекундах: `Math.round(60000 / bpm)`.
4. `timerId = setInterval(tick, period)`.
5. `running = true`, текст кнопки — «Стоп».

### Шаг 4. `stop()`

Если `timerId !== null` — `clearInterval(timerId)` и `timerId = null`. Затем `running = false`, текст кнопки — «Старт».

### Шаг 5. `changeBpm(delta)`

1. `bpm = bpm + delta` (кнопки уже передают −5 и +5).
2. Зажми диапазон: меньше 40 → 40, больше 240 → 240.
3. `updateView()`.
4. Если метроном уже идёт (`running`) — вызови `start()`, чтобы интервал пошёл с новым BPM.

### Шаг 6. Проверь в браузере

Старт даёт клик и пульс, стоп молчит, ±5 меняет число и темп. Если застрял — F12.

## Критерии сдачи

- [ ] Старт / стоп работают
- [ ] BPM меняется в диапазоне 40–240
- [ ] Кружок пульсирует
- [ ] На каждый удар слышен клик
- [ ] Для 120 на экране `Allegro`
- [ ] Нет красных ошибок в консоли

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| Тишина | Вызов `playClick` должен остаться в `tick`; клик «Старт» создаёт AudioContext |
| Интервал не сбрасывается | Перед новым `setInterval` сделай `clearInterval` |
| BPM уехал за край | Зажми значение между 40 и 240 |
| На экране «—» вместо темпа | Допиши `tempoName`; для 120 верни `Allegro` |
| Смена BPM на ходу не меняет скорость | В `changeBpm` при `running` снова вызови `start()` |
