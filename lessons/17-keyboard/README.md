# Урок 17. Виртуальная клавиатура

Семь белых клавиш одной октавы. По клику клавиша подсвечивается, на экране имя ноты, в наушниках — тон.

Этот урок — **1 час**, в одной паре с уроком 18.

### Имена нот

В коде удобны латинские буквы. Это те же ступени, что «До Ре Ми» на уроке 8:

| Клавиша | C | D | E | F | G | A | B |
|---------|---|---|---|---|---|---|---|
| По-русски | До | Ре | Ми | Фа | Соль | Ля | Си |

**B** здесь — это Си. Не путай с немецкой буквой H.

## Цели

- по клику показать имя ноты;
- сыграть частоту из готовой таблицы;
- снять подсветку через короткое время.

## Что понадобится

- Уроки 11–16
- Папка `lessons/17-keyboard/starter`

## Тайминг (~1 ч)

| Этап | Время |
|------|-------|
| Разбор starter и словарь нот | ~10 мин |
| Клик по клавише | ~20 мин |
| Звук из таблицы частот | ~15 мин |
| Проверка | ~15 мин |

## Пошаговое задание

### Шаг 1. Открой starter

Открой `starter/index.html` — семь клавиш уже в разметке. Клики повешены циклом `for` (как на уроке 9): индекс `0` — C, `6` — B. `playTone` уже написан, как `playA4` на уроке 6.

### Шаг 2. Допиши `pressKey(index)`

`note` и `key` уже найдены. Внутри функции:

1. Покажи имя ноты: `nameEl.textContent = note.name`.
2. Сыграй частоту из массива: `playTone(note.freq)` — не хардкодь 440.
3. Подсвети клавишу и сними через 200 мс (как вспышка на метрономе):

```js
key.classList.add("on");
setTimeout(function () {
  key.classList.remove("on");
}, 200);
```

### Шаг 3. Проверь в браузере

Каждая клавиша пишет свою букву и играет свой тон. Если застрял — F12.

## Критерии сдачи

- [ ] 7 клавиш реагируют на клик
- [ ] Имя ноты появляется на экране
- [ ] Слышен тон (у C и A разная высота)
- [ ] Подсветка снимается через 200 мс
- [ ] Нет красных ошибок в консоли

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| Все клавиши играют ля | Передай `note.freq` из массива, не хардкодь 440 |
| Подсветка не снимается | `setTimeout` и `classList.remove` |
| Звука нет | `playTone` вызови из `pressKey`, не в начале файла |
| На экране «Допиши pressKey…» | Замени заглушку на `note.name` |
