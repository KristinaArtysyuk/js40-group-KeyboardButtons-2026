# Урок 18. Плейлист: выбор и «сейчас играет»

На уроках 9 и 11 список треков уже выводили. Сегодня новый навык: **клик по строке, которую создал цикл**. Выбранный пункт подсвечивается, в блоке «Сейчас играет» — его название.

Этот урок — **1 час**, в одной паре с уроком 17.

## Цели

- отрисовать список из массива;
- повесить клик на каждый `li` **в момент создания**;
- хранить текущий индекс;
- (по желанию) короткий тон при выборе.

## Что понадобится

- Уроки 11–13 и 17
- Папка `lessons/18-playlist/starter`

## Тайминг (~1 ч)

| Этап | Время |
|------|-------|
| Массив и отрисовка | ~15 мин |
| Клик и подсветка | ~20 мин |
| «Сейчас играет» | ~10 мин |
| Проверка | ~15 мин |

## Пошаговое задание

### Шаг 1. Открой starter

Открой `starter/index.html`. Массив `tracks` и функция `selectTrack` уже есть: она запоминает индекс, пишет название в `#now-playing` и вызывает `render()`. Тебе нужно дописать тело `render`.

### Шаг 2. Цикл в `render()`

Список уже очищается (`innerHTML = ""`). Циклом `for` по `tracks`:

```js
const li = document.createElement("li");
li.textContent = tracks[i];
```

Если эта строка выбранная — подсвети её:

```js
if (i === currentIndex) {
  li.classList.add("current");
}
```

Повесь клик **на этот `li`**, передай именно `i` этой строки:

```js
li.addEventListener("click", function () {
  selectTrack(i);
});
listEl.appendChild(li);
```

### Шаг 3. Проверь в браузере

Четыре трека на экране. Клик подсвечивает **один** пункт, «Сейчас играет» совпадает с ним. Если застрял — F12.

Новое относительно урока 11: не кнопки «добавить / случайный», а выбор текущего трека кликом по самому списку.

## Критерии сдачи

- [ ] Список виден на странице
- [ ] Клик подсвечивает **один** пункт
- [ ] Блок «Сейчас играет» совпадает с выбранным
- [ ] Нет ошибок в консоли

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| Подсвечены все | Класс `current` только у выбранного индекса |
| Список дублируется | `innerHTML = ""` перед циклом |
| Клик не ловится | Вешай обработчик на `li` в момент создания |
| Всегда играет первый трек | В обработчик передай именно `i` этой строки (как `let` в цикле на уроке 17) |
