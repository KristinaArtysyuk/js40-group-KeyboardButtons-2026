# Урок 19. README портфолио и Issues

Commit и push вы уже делаете с урока 1. Сегодня аккуратнее README и (по желанию) Issues в **своём** репозитории.

Сдача — Pull Request в репозиторий **группы**. Merge не нажимаем.

## Цели

- повторить clone / commit / push своими словами;
- страница «Музыкальный профиль» в `lessons/19-git-portfolio/starter/`;
- README папки: название, как открыть, автор;
- (stretch) две Issues в своём репозитории.

## Что понадобится

- Свой репозиторий и Git
- `lessons/19-git-portfolio/starter`

## Пошаговое задание

### Шаг 1. Цепочка

| На диске | В Git |
|----------|-------|
| Файлы в редакторе | рабочая копия |
| Сохранить версию с комментарием | commit |
| Отправить версию на GitHub | push |
| Скачать копию себе | clone |

С урока 1 цепочка та же: **править папку урока → commit → push**.

### Шаг 2. Профиль

1. Открой `lessons/19-git-portfolio/starter/index.html`.
2. Подставь имя, инструмент, жанры.
3. Поменяй цвет в `style.css`.

### Шаг 3. Commit и push

```bash
git add .
git commit -m "урок 19: музыкальный профиль"
git push
```

### Шаг 4. README

Скопируй `starter/README-template.md` в `starter/README.md` (та же папка). Заполни все «…». Нужны заголовки и список.

## Критерии сдачи

- [ ] На GitHub видны обновлённые имя/цвета
- [ ] Есть commit с понятным сообщением
- [ ] README: название, как открыть `index.html`, автор
- [ ] Можешь вслух сказать: commit — снимок, push — отправка в облако

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| `git status` ничего не показывает | Сохрани файл; открыта та же папка |
| Сообщение `asdf` | Пиши по делу: «Добавил инструмент» |
| PR в репозиторий курса | Закрой его, сдай ссылку на **свой** repo |

## Домашнее задание

**Must:** второй commit (цитата музыканта или любимая пьеса) + README.

**Stretch:** две Issues в своём репозитории («добавить фото», «тёмная тема»).
