# Урок 20. Парный проект — день 1

Сегодня работаете **в паре**: один отвечает за HTML и CSS, другой — за JavaScript. Файлы лежат в **общем** репозитории.

Выберите **одну** тему. У каждой есть стартер: движок уже работает, пара наполняет своими данными и оформлением. Не сдавайте файлы курса как есть.

## Цели

К концу урока пара сможет:

- выбрать тему;
- создать общий репозиторий и добавить напарника collaborator (напарник с правом править файлы);
- договориться, кто делает UI, кто — JS;
- сделать промежуточный commit и push.

Ветки `feature/ui` и `feature/logic` можно, но не обязательно. Если оба правят один файл — договоритесь вслух.

## Что понадобится

- Пара (2 человека)
- Аккаунты GitHub у обоих
- Git
- Стартер выбранной темы в `lessons/20-pair-project-start/`
- Шаблон README: `templates/pair-project/README.md`

## Пошаговое задание

### Шаг 1. Правила пары

1. Один репозиторий на двоих.
2. Не ломайте работу напарника.
3. Пишите понятные сообщения commit.
4. Раз в ~20–30 минут — push.
5. Споры: «сначала работает, потом красиво».

### Шаг 2. Выберите тему (одна на пару)

Скопируйте папку стартера **в корень** репозитория пары (`index.html` рядом с README).

| Тема | Папка | Что дописать паре |
|------|--------|-------------------|
| 1. Викторина | `starter/` | 10+ **своих** вопросов, подписи, оформление |
| 2. Список репетиций | `starter-rehearsals/` | Свои даты и пьесы, вид формы |
| 3. Карточки терминов | `starter-cards/` | 8+ **своих** терминов, вид карточки |
| 4. Рандомайзер пьес | `starter-randomizer/` | Свой репертуар (≥ 3 пьес), оформление |
| 5. Метроном+ | `starter-metronome-plus/` | Своё оформление (клик, размер такта и акцент уже есть) |
| 6. Клавиатура+ | `starter-keyboard-plus/` | Своё оформление; игра с A–J уже есть. Stretch — чёрные клавиши |
| 7. Плейлист+ | `starter-playlist-plus/` | Свой список треков, вид списка |

Несколько пар могут взять одну тему — у каждой свой репо и свои данные.

### Шаг 3. Репозиторий и роли

1. Один из пары создаёт репозиторий.
2. Settings → Collaborators → добавить напарника.
3. В README: тема, кто UI, кто JS, как открыть `index.html`. Можно скопировать `templates/pair-project/README.md`.
4. Скопируйте файлы стартера темы в корень репозитория пары.

### Шаг 4–5. Работа и push

К концу занятия страница открывается. Каждый делает commit в репозиторий пары. Pull Request в `js-music-course-40h` не нужен.

## Критерии сдачи (день 1)

- [ ] Есть общий репозиторий, оба имеют доступ
- [ ] В README указаны тема и роли
- [ ] Есть push с осмысленным commit
- [ ] Страница открывается в браузере

## Типичные ошибки

| Ошибка | Что делать |
|--------|------------|
| Нет collaborator | Settings → Collaborators |
| «Я сделаю всё сам» | Цель урока — работа вдвоём |
| Пустой README | Без него не поймут запуск |
| Слишком большая тема | Урежьте до минимума из урока 21 |
| Сдали стартер как есть | Добавьте свои вопросы / данные / оформление |
