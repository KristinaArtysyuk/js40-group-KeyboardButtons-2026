# Урок 21. Парный проект — день 2: слияние и финал

Второй день пары: доводим **выбранную тему** до минимума ниже. Стартер темы уже умеет главный сценарий — его нужно наполнить своими данными и оформлением, а не сдавать файлы курса как есть.

## Цели

- закончить минимум по выбранной теме;
- проверить запуск в браузере;
- подготовить ссылку на GitHub и роли к защите.

## Минимум по темам

Сдаёте **одну** тему. Чего нет в списке — не требуется.

### 1) Викторина

- [ ] Экран старта с кнопкой «Начать»
- [ ] Не меньше 10 **своих** вопросов на русском
- [ ] 4 варианта ответа, подсветка верно/неверно
- [ ] Счёт и оценка: 5 / 4 / 3 / 2
- [ ] Кнопка «Пройти ещё раз»
- [ ] README: как открыть и кто что делал

Стартеры всех тем лежат в `lessons/20-pair-project-start/` (`starter/`, `starter-rehearsals/`, `starter-cards/`, `starter-randomizer/`, `starter-metronome-plus/`, `starter-keyboard-plus/`, `starter-playlist-plus/`).

### 2) Список репетиций

- [ ] Форма: дата, произведение, заметка
- [ ] Список пополняется на странице
- [ ] Можно удалить пункт
- [ ] README с ролями

### 3) Карточки терминов

- [ ] Не меньше 8 карточек
- [ ] По клику видно определение (переворот или смена текста)
- [ ] Кнопка «следующая»
- [ ] README с ролями

### 4) Рандомайзер пьес

- [ ] Можно добавить пьесу
- [ ] Кнопка показывает 3 случайных без повторов (если пьес ≥ 3)
- [ ] Понятное сообщение, если пьес мало
- [ ] README с ролями

### 5) Метроном+

- [ ] Старт / стоп, слышен клик, меняется BPM
- [ ] Если метроном запущен, смена BPM не ломает пульс (перезапуск интервала)
- [ ] Размер такта и акцент первой доли
- [ ] README с ролями

### 6) Клавиатура+

- [ ] Не меньше 7 клавиш, слышна нота, имя на экране
- [ ] Одно своё улучшение: больше клавиш **или** чёрные клавиши **или** игра с клавиатуры компьютера
- [ ] README с ролями

### 7) Плейлист+

- [ ] Список на странице, «сейчас играет», подсветка выбранного
- [ ] Можно добавить трек и удалить трек
- [ ] README с ролями

## Критерии сдачи (день 2)

- [ ] Минимум по теме выполнен
- [ ] В README указаны авторы и роли
