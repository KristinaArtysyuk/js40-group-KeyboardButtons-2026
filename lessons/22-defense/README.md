# Урок 22. Защита проекта

Короткая защита: 5 минут, спокойно, со ссылкой на GitHub. Это не экзамен на отчисление.

## Цели

- провести демо по чек-листу;
- назвать роли;
- сказать, что было сложно и чему научились;
- оставить README как портфолио (список ДЗ + ссылка на парный проект).

## Тайминг (~2 ч)

| Этап | Время |
|------|-------|
| Как устроена защита | ~15 мин |
| Заполнение чек-листа | ~20 мин |
| Репетиция в парах | ~20 мин |
| Защиты | ~45 мин |
| Итоги | ~10 мин |

Чек-лист: `starter/defense-checklist.md`.

Структура 5 минут: название → демо в браузере → роли → сложности.
