# Шаблон страницы

Правь файлы в `lessons/…/starter/` нужного урока. Этот шаблон — запасной, если у урока нет starter.

Слова Must / Stretch / starter — в [README.md](../../README.md).

## Как открыть

1. Открой `index.html` в браузере (двойной клик).
2. Правь `style.css` и `script.js`.
3. Смотри ошибки во вкладке Console (F12).

## Что сдать

Push в свой форк, затем Pull Request в репозиторий группы. Merge не нажимай.
